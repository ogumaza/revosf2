revosf2 1.6.0 converts New Play Control! Donkey Kong Jungle Beat's music once more in each state that the game sets during play.

Requires 64-bit Windows 10 or later, with no additional runtime DLLs. Drop one or more `.brsar`, `.baa` or `.aaf` files, game folders or disc images onto `revosf2.exe`, or use a terminal. `revosf2 --help` lists the options. Output goes in a folder beside each input.

For macOS on Apple Silicon, follow the build instructions in the README. macOS builds include `Revosf2.app`. Drop archives onto the app in Finder to convert them. The app takes only `.brsar`, `.baa` and `.aaf` files. Convert games from a terminal.

## Changes since 1.5.0

- **New Play Control! Donkey Kong Jungle Beat's music in the game's states.** The game turns tracks on or off as play goes on: as a combo grows, while a Helibird carries DK, in each part of a boss fight, and while DK swims deep in TropicalCoast. revosf2 converts 44 pieces once more in each such state, 102 files in all. A file is named after the piece and what sets its state, for example `JA_BGM_MAIN_01_combo1` and `_combo2` for the layers of a combo, `_helibird` for a flight with a Helibird, `_round2` and `_change` for a boss's second round and the change before it, and `_underwater` for TropicalCoast's music while DK swims below. As the menus do, `JA_BGM_COURSE_SELECT_state1` plays the map's music with two tracks off. Each file plays its state from the piece's start. The game fades from one state to the next, and the files leave out those changes.
- **Read errors with the right file.** When a conversion of a JAudio game failed after a bank or a wave couldn't be read, the read error appeared with the next file. That file might not use the bank. The failed conversion's message now ends with its read errors.
- **Extracted discs with a folder that can't be opened.** revosf2 stopped listing an extracted disc's `files` folder at the first subfolder that it wasn't allowed to open. It gave no message and left out the files after that folder. It now goes on past such a folder.
- **A finished track's port.** A JAudio2 sequence that read a port of a child track after the track had finished took the track's last value. The game reads nothing then, and revosf2 now does the same.
- **Names outside the code page on Windows.** revosf2 couldn't convert an archive, a game folder or a disc image whose path held a character outside Windows' code page, such as a Japanese title. revosf2 now uses UTF-8 for its paths on Windows 10 version 1903 and later.
- **The libraries.** revosf2 now builds on ntdlib 3.6.0, with xsflib 1.10.0 and seqlib 1.4.0.
- **Builds on Windows.** The build now stops with a message for a Windows compiler other than clang-cl, such as MSVC's cl.exe or MinGW's GCC. The README gives the steps for clang-cl.

## Known limitations

As in 1.5.0. The Galaxy games' other effects that take values from play still convert with those values at 0. See "Differences from the game" and "JAudio games" in the README for the full list.
