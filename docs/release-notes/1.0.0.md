First release of revosf2, a MIDI, SoundFont 2 and SFZ converter for Nintendo Wii sound archives (`.brsar`). It executes sequences using the game's playback rules and records the result. Each sequence gets a MIDI file and a SoundFont containing its instruments. The SFZ files add the game's filters: the one-pole low-pass and the biquad of the builds from 2008. SoundFont can only approximate them or leave them out.

Requires 64-bit Windows 10 or later, with no additional runtime DLLs. Drop one or more `.brsar` files onto `revosf2.exe`, or use a terminal. `revosf2 --help` lists the options. Output goes in a folder beside each archive.

For macOS and Linux, follow the build instructions in the README. macOS builds include `Revosf2.app`. Drop archives onto the app in Finder to convert them.

## What it does

- **Sequence playback.** Follows the WSF project's model of the Wii's sound library, NW4R SND. That covers variables, random arguments, calls, loops and tracks that start other tracks. Uses the game's 3 ms timing and random generator. The game's `main.dol` gives the library's build, and the archive plays by that build's rules: those of 2006, of 2007, or from March or June 2008. revosf2 finds `main.dol` in an extracted disc, or takes it with `--dol`. Without it, revosf2 goes by the archive's version: the rules of 2008 for version 1.4 or later, and those of 2007 for older versions. The loop markers go on a pass of the main loop that a player looping on them repeats as the game plays the next pass. A main loop that starts no note gets no markers once the notes before it have ended. The sequence then ends with its last sound. A note that plays until its track releases it, such as a tie, ends where it has faded 60 dB.
- **MIDI.** Each sequence track gets a MIDI track and channel of its own. Volume, pan, pitch bend, LFO depth, effect sends and filter changes become controllers.
- **SoundFont.** Each combination of instrument and track settings becomes a preset, with the game's samples, tuning, volumes, envelopes and loops. Output targets FluidSynth.
- **SFZ.** One file per sequence track, with the game's filters and WAV samples. Output targets sfizz 1.2.
- **Archives.** Reads RSAR archives with PCM8, PCM16 and DSP-ADPCM waves, in banks of both versions. Converts what a truncated archive still holds. An unreadable archive reports an error without stopping the remaining conversions.
- **Reports.** Lists approximations required by MIDI, SoundFont or SFZ for each sequence.

## Known limitations

- Streamed music and wave sounds are not converted.
- MIDI pitch bend applies to a whole channel. Game sweeps, portamento and legato key changes apply to individual notes. A note that sweeps beside another goes on a channel of its own while MIDI's 16 channels last.
- A legato requires a new MIDI note when envelope or LFO settings change. The new note restarts the sample and envelope. The game continues the existing note.
- A SoundFont's attack rises linearly, and the game's rises exponentially in decibels. Slow attacks start louder in the SoundFonts.
- SoundFont provides a two-pole low-pass filter. That filter approximates the game's one-pole filter and matches the low-pass of the biquad in the builds from 2008. SoundFont leaves out the biquad's high-pass and band-passes. The SFZ files have them.
- Synth interpolation differs from AX's resampling, mainly above 8 kHz.
- See "Differences from the game" in the README for the full list.
