A feature release: revosf2 converts whole games, WiiWare titles among them, and finds the sound archives that some games keep inside CRI Middleware's CPK archives. The SoundFonts also follow the game's filters and tremolos more closely. Convert an archive again to get the corrected files.

Requires 64-bit Windows 10 or later, with no additional runtime DLLs. Drop one or more `.brsar` files, game folders or disc images onto `revosf2.exe`, or use a terminal. `revosf2 --help` lists the options. Output goes in a folder beside each input.

For macOS on Apple Silicon, follow the build instructions in the README. macOS builds include `Revosf2.app`. Drop archives onto the app in Finder to convert them. The app takes only `.brsar` files. Convert games from a terminal.

## New

- **Games.** An input can be a whole game: an extracted disc, a WiiWare title's folder with the title's TMD and decrypted contents, or a disc image whose game partition is stored decrypted, such as an NKit image. revosf2 converts each sound archive in the game into a folder of its own. The folders go inside `<game name>_revosf2` beside the game. The game's `main.dol`, or a title's main program, gives the build of the sound library. A WiiWare title holds no file named `main.dol`. An archive taken out of one used to play by its version.
- **CPK archives.** Some games keep their sound archives inside CRI Middleware's CPK archives. A CPK stores each file as it is or compresses it with CRILAYLA. revosf2 finds and converts the sound archives in both forms.
- **Images that revosf2 can't read.** revosf2 can't decrypt a game partition. It doesn't read RVZ, WIA, GCZ or CISO images either. For those, and for a WAD, its message says what to give it instead. Dolphin's Extract Entire Disc makes a folder that revosf2 reads.

## Fixes

- **AX's resampling.** AX resamples each note with filters chosen when the note starts. They darken a note that plays more than one sample per output sample. The SoundFont zones and SFZ regions of such notes now take low-passes fitted to AX's filters. Such notes used to play brighter than in the game.
- **The track low-pass at low cutoffs.** The SoundFont's two-pole low-pass played a strongly filtered note several decibels louder than the game's one-pole filter does. Each zone now takes the cutoff at which FluidSynth passes as much of its sample as the game's filter. The SFZ files still play the game's filter.
- **Tremolos above full level.** The game never takes a note above full level. While a note's envelope is at full level, the upper half of its tremolo changes nothing. A note that the game holds at full level now swings less, from a lower level. The swing is fitted to the game's level. Such a note used to swing above full level.

## Known limitations

As in 1.0.1, apart from the changes above. `Revosf2.app` doesn't take games. See "Differences from the game" in the README for the full list.
